# Breeze Max — HVAC Landing Page

A modern, high-conversion landing page for **Breeze Max**, an HVAC (Heating, Ventilation, and Air Conditioning) service company serving the Dallas–Fort Worth metro.

Built with **Next.js 14**, **React 18**, **Tailwind CSS**, and **Lucide icons**.

---

## ✨ Features

- **Hero section** with animated thermostat dial and live status indicator
- **Service grid** — 6 HVAC services with photo + icon variants
- **How it works** — 3-step process with trust badges
- **Interactive cost estimator** — real-time price range based on home size and system type
- **Lead capture form** — with mailto fallback + Formspree-ready endpoint
- **Three contact channels:**
  - Direct mobile dialer (`tel:` link)
  - Smart WhatsApp trigger (prefilled from form state)
  - Functional email form
- **Floating action buttons** — instant call & WhatsApp on scroll
- **Fully responsive** — mobile-first design with smooth animations
- **Single source of truth** — all content lives in one `HVAC_ASSETS` object for easy editing
